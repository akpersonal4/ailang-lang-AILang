# AILang v1.1.4 Release Notes

**Release Date:** 2026-07-24

**Release Type:** Patch

## Summary

v1.1.4 is a patch release that fixes a stdlib module resolution bug (MOD003) discovered during external validation. This is a targeted bug fix with no language changes, no breaking changes, and no API changes.

---

## Bug Fix

### MOD003: Stdlib Module Resolution from Outside Project Tree

**Issue:** Programs importing stdlib modules (`string`, `math`, `list`, `map`, `json`, etc.) would fail with `ERROR MOD003: Module not found` when compiled or run from a directory outside the project tree (e.g., from a temp directory or a different project).

**Root Cause:** `ModuleResolver._candidate_roots()` in `compiler/compilation/resolution.py` only searched the local filesystem hierarchy upward from the source file. It did not check the installed package's stdlib directory as a fallback.

**Fix:** Added `_find_stdlib_root()` helper function and updated `_candidate_roots()` to include the installed package's stdlib as a fallback search path. This mirrors the logic already present in `compiler/cli/main.py:_find_stdlib()`.

**Verification:** All 1018 tests pass. Four new integration tests (`tests/test_mod003_stdlib_resolution.py`) permanently protect against this regression.
