## Remaining Technical Debt (For v1.2.0 Consideration)

| Item | Description | Effort |
|------|-------------|--------|
| **Registry code duplication** | `compiler/package/registry.py` and `tools/ail_package_manager/registry.py` overlap significantly (both have: `_registry_urljoin`, `load_registry_url`, `pack_project`, `_build_package_metadata`, `publish_local`, `publish_remote`). The `tools/` version is richer; the `compiler/` version is what the CLI imports. | Medium |
| **Test `return` warnings** | 60+ tests use `return` instead of `assert` for test results, triggering `PytestReturnNotNoneWarning`. These work correctly but should be converted for style. | Low |
| **pytest.mark.slow** | `tests/test_mod003_stdlib_resolution.py` uses `@pytest.mark.slow` without registering the custom marker, causing `PytestUnknownMarkWarning`. Add to `pyproject.toml [tool.pytest.ini_options]`. | Trivial |
| **ImportDeclarationNode spans** | `tests/test_lsp.py:588` NOTE documents that `ImportDeclarationNode` spans are `None`. This is a known parser bug that should be fixed. | Medium |
| **`package-lock.json` stale** | `extensions/vscode-ailang/package-lock.json` shows `1.1.1` — autogenerated but out of sync. | Low |

## Recommendations for v1.2.0

1. **Consolidate the two registry implementations** — `compiler/package/registry.py` and `tools/ail_package_manager/registry.py` should be unified.
2. **Fix `ImportDeclarationNode` span bug** — referenced in `tests/test_lsp.py:588`.
3. **Register `slow` pytest marker** in `pyproject.toml` to eliminate the warning.
4. **Convert `return`-based test assertions** to `assert`-based across all acceptance tests.
5. **Regenerate `package-lock.json`** for the VSCode extension.
